# RAG 混合检索效果评估报告

## 评估方法

**Ground Truth 定义**：基于 5 份人工编写的测试文档（共覆盖 PostgreSQL 索引优化、微服务架构、Docker 部署、消息队列选型、API 网关设计 5 个技术领域），由人工标注每个测试 query 应命中的文档段落（expectedChunks）。测试文档通过正常上传流程入库后，通过文本子串匹配将标注映射到实际 chunk ID。

**评估指标**：
- **Recall@5**：Ground Truth 中有多少比例出现在各方法的 top-5 结果中
- **Precision@5**：各方法 top-5 结果中有多少比例属于 Ground Truth
- **MRR**（Mean Reciprocal Rank）：Ground Truth 文档在各方法结果中的平均排名倒数

## 汇总结果

| 指标 | 纯向量 | 纯关键词 | 混合检索+重排 |
|------|--------|---------|----------|
| 平均 Recall@5 | 0.9056 | 0.6111 | **0.8500** |
| 平均 Precision@5 | 0.2667 | 0.1733 | **0.2400** |
| 平均 MRR | 0.7058 | 0.4356 | **0.7013** |

**混合检索（含 LLM 重排）vs 纯向量 Recall 提升：-6.1%**
