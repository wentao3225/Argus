# 数据模型设计说明

## 数据库整体设计

Argus 使用 PostgreSQL 16 作为主数据库，数据表按功能模块划分。

## 用户相关表

### users 表

存储用户基本信息：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| user_code | VARCHAR(50) | 用户编码，唯一 |
| username | VARCHAR(100) | 用户名，登录用 |
| email | VARCHAR(255) | 邮箱 |
| display_name | VARCHAR(200) | 显示名称 |
| password_hash | VARCHAR(255) | BCrypt 加密的密码 |
| system_role | VARCHAR(20) | 系统角色（ADMIN/USER） |
| status | VARCHAR(20) | 用户状态 |
| must_change_password | BOOLEAN | 是否强制修改密码 |

## 群组相关表

### groups 表

知识库群组主表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| group_name | VARCHAR(200) | 群组名称 |
| group_code | VARCHAR(50) | 群组编码，用于搜索和加入 |
| description | TEXT | 群组简介 |
| status | VARCHAR(20) | 状态（ACTIVE/ARCHIVED） |

### group_memberships 表

群组成员关系表：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| group_id | BIGINT | 群组 ID |
| user_id | BIGINT | 用户 ID |
| role | VARCHAR(20) | 角色（OWNER/MEMBER） |
| status | VARCHAR(20) | 状态 |

## 文档相关表

### documents 表

文档主表，记录文档元数据：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| group_id | BIGINT | 所属群组 |
| uploader_user_id | BIGINT | 上传者 |
| file_name | VARCHAR(500) | 文件名 |
| file_ext | VARCHAR(20) | 扩展名 |
| file_size | BIGINT | 文件大小（字节） |
| file_hash | VARCHAR(64) | SHA-256 哈希 |
| status | VARCHAR(20) | 状态（UPLOADED/PROCESSING/READY/FAILED） |
| deleted | BOOLEAN | 软删除标记 |

### document_chunks 表

文档切片表，存储解析后的文本切片：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGSERIAL | 主键 |
| document_id | BIGINT | 所属文档 |
| group_id | BIGINT | 所属群组 |
| chunk_index | INTEGER | 切片序号 |
| chunk_text | TEXT | 切片文本内容 |
| char_start | INTEGER | 在原文档中的起始位置 |
| char_end | INTEGER | 在原文档中的结束位置 |

### upload_sessions 表

分片上传会话表：

| 字段 | 类型 | 说明 |
|------|------|------|
| upload_id | VARCHAR(64) | 会话 ID |
| group_id | BIGINT | 群组 ID |
| file_name | VARCHAR(500) | 文件名 |
| file_size | BIGINT | 文件大小 |
| file_hash | VARCHAR(64) | 文件哈希 |
| chunk_size | INTEGER | 每片大小 |
| chunk_count | INTEGER | 总片数 |
| status | VARCHAR(20) | 状态 |

## 向量存储

向量数据由 Spring AI VectorStore 自动管理，表名固定为 vector_store：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| content | TEXT | 向量对应的文本 |
| metadata | JSON | 元数据（含 documentId、chunkId、groupId 等） |
| embedding | vector(512) | 512 维嵌入向量 |

使用 HNSW 索引加速最近邻搜索。
