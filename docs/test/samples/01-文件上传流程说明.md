# 文件上传流程说明

## 概述

Argus 知识库平台支持两种文件上传方式：直接上传和分片上传。

## 直接上传

直接上传适用于 10MB 以下的小文件。用户在前端选择文件后，系统自动上传并触发后续的 ETL 处理流程。

### 使用步骤

1. 进入目标知识库群组
2. 点击"添加文档"按钮
3. 选择文件（支持 TXT、MD、PDF、DOCX 格式）
4. 等待上传完成
5. 系统自动开始解析处理

### 注意事项

- 文件大小不能超过 256MB
- 支持的文件格式：.txt、.md、.pdf、.docx
- 上传后文档状态变为 PROCESSING，处理完成后变为 READY

## 分片上传

分片上传适用于大于 10MB 的大文件。系统将文件切割为多个 5MB 的分片，逐个上传，最后合并。

### 分片上传流程

1. 调用初始化接口创建上传会话
2. 逐个上传文件分片
3. 所有分片上传完成后，调用完成接口合并分片
4. 合并完成后自动触发 ETL 处理

### 断点续传

如果上传过程中断，重新初始化时系统会自动检测已上传的分片，只需上传缺失的分片即可。

## 上传后的处理流程

上传完成后，系统自动执行以下步骤：

1. 文档解析：根据文件格式选择合适的解析器
2. 文本清洗：去除无关字符
3. 文本切片：按结构感知策略切分为多个 chunk
4. 向量化：调用 Embedding 模型生成向量
5. 索引入库：写入 PostgreSQL

## 常见问题

### Q: 上传后文档状态一直为 PROCESSING 怎么办？
A: 这是正常现象。ETL 处理需要一定时间，取决于文档大小。如果长时间未变，请检查后端日志。

### Q: 上传失败怎么办？
A: 检查文件格式是否支持、文件大小是否超限、网络连接是否正常。可以在前端点击"重试"按钮。

### Q: 如何确认上传成功？
A: 文档列表中该文档的状态变为 READY 即表示处理完成。
